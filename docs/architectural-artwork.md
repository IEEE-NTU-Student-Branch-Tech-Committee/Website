# NTU and Singapore architectural panorama

Final website asset: `public/images/ntu-singapore-linework.webp` (2172 × 724, approximately 304 KiB). Created with the built-in image generation tool, then encoded as WebP at quality 90. No CLI image generator or API key was used. This is a decorative generated illustration, not a photograph, official campus drawing, logo or geographic map.

The generation returned white/light-blue ink on an opaque black background, despite the transparency request. The website uses an SVG luminance mask to show only the drawn lines and apply a semantic theme colour. We do not describe the source file as alpha-transparent. The master output is preserved separately; the checked-in WebP is sufficient for ordinary builds.
